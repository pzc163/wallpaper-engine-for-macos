# Space Wallpaper ASCII 网页壁纸支持

截图中的错误来自 Rust 的类型预检：Web 项目被直接拒绝，和已修复的 Scene/3D 渲染不同。原始资产 3812890863 使用本地 index.html、space.js、内嵌图片和 WebGL 2，并通过 wallpaperPropertyListener 接收属性、FPS 和暂停状态。

采用系统 WebKit，新增核心层的网页渲染后端，复用 Rust 显示器、窗口和生命周期。相比在 Swift UI 单独维护窗口，这样能统一屏幕分配和重启恢复；相比引入 Chromium，避免新的大型运行时依赖。每个显示器使用独立 WKWebView，视图挂在本地 bounds 原点；WebKit 负责 Retina 和 WebGL。

加载前验证入口存在且规范化路径位于项目目录内。网页导航、脚本错误返回引擎错误；候选窗口成功加载后才替换旧壁纸。只允许项目目录本地读取，不启用私有的跨域/任意文件访问开关。桥接传递默认属性及用户覆盖、FPS、暂停、音量和全局鼠标输入。原始创意工坊资源保持不变。

验收：路径和属性合并单元测试，桥接 JS 行为测试，核心回归与新 app 编译；在实际副屏加载原始 Space Wallpaper ASCII，验证 WebGL 动画、属性更新、暂停恢复、Scene/Web 切换和冷启动，同时保持主屏正常。记录新构建路径、版本、哈希、日志及真实窗口截图。本次不声称支持所有网页壁纸的音频频谱、媒体集成或目录权限 API。
