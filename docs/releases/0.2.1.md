# 0.2.1（2026110905）

本次正式版本冻结自双屏实机验收的 0.2.1（2026110905）。发布时封装动态库并重新进行 ad-hoc 签名，没有重新编译或改变已验收应用的可执行指令。原始程序 SHA-256 为 `61358505558eb6ff665b726067d4f4a37a70e5d22bd82f430ee5f49d260379f4`；打包后的文件校验值以 Release 中的 `SHA256SUMS.txt` 为准。

## 变更

- 修复 Ender 全特效的跨尺寸纹理复制、离屏同步和图层合成重影/过曝。
- 增加场景 3D 模型、透视相机、光源、深度缓冲及 32 位索引支持，覆盖实时地球所需的渲染路径。
- 增加本地网页壁纸的 WebKit/WebGL 后端及属性、暂停、帧率和输入桥接。
- 修复 MUSIC STARS 的加载遮罩不消失、动态外观脚本、隐藏图层模板、MDLV16 静态模型、全屏合成裁切及文字队列饥饿。
- 修复巨大数值范围滑块造成设置界面卡死，以及表面重建时残留绘制消息导致的崩溃。

渲染子模块固定到 `pzc163/open-wallpaper-engine` 的 `e5bfeb9553201e2ad894ed8762e3a2e500ca661e`。克隆时需要 `--recurse-submodules`，也可下载 Release 中包含子模块的完整源码包。

## 打包已编译应用

已有可运行的 Release 应用时，可通过下列脚本复制并封装依赖，原始应用不会被修改：

```sh
python3 scripts/package-macos.py \
  --source-app 'build/Release/Wallpaper Engine.app' \
  --output-app 'dist/0.2.1/Wallpaper Engine.app' \
  --moltenvk /opt/homebrew/opt/molten-vk/lib/libMoltenVK.dylib

python3 scripts/package-macos.py \
  --output-app 'dist/0.2.1/Wallpaper Engine.app' --verify-only
```

脚本会拒绝覆盖已有输出目录；发现缺失动态库、重名冲突或可执行指令变化时立即失败。依赖采用相对安装名，MoltenVK 清单相对于资源目录定位内置驱动，符合 [Vulkan Loader 驱动清单说明](https://github.com/KhronosGroup/Vulkan-Loader/blob/main/docs/LoaderDriverInterface.md)。

Nix 构建入口仍为 `nix build`，源码中的应用版本和构建号已固定为 0.2.1 / 2026110905。不同依赖版本或工具链的重新构建不保证与已验收发布附件逐字节相同。
